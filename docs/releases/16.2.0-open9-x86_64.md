# GFOpenAmigaGCC 16.2.0-open9 for x86_64-linux-gnu

A cross compiler on x86-64 Linux for x86-64 Linux kernels: the AMD x86 appliance (Debian 13 amd64). It is built as `x86_64-gfopen-linux-gnu`, so GCC does not take it for a native compiler, and every program is also there as `x86_64-linux-gnu-NAME`. It is GCC 16.2.0 and binutils 2.47 as GNU released them, with one fix from the m68k toolchains and the open9 name.

## What is in it

- GCC 16.2.0 and binutils 2.47, the same tarballs and SHA-256 as the m68k-aros target (`scripts/linux.lock`).
- `patches/gcc/0019` (fold-mem-offsets, from open8): the pass no longer takes an instruction with memory on both sides as an access through its source's base only. It is in GCC's target-independent code, so it goes in here too (`patches/linux/series`).
- The compiler says `GFOpenAmigaGCC 16.2.0-open9`.
- Nothing of AmigaOS: no driver defaults, libnix, pthreads (aros-stuff 0011) or libstdc++ change.

It is a kernel compiler, like the kernel.org cross compilers: C only, and libgcc without a C library. There is no glibc and no C++, so it does not build Linux programs. GMP, MPFR and MPC are linked in statically: the programs need only the host's C library (glibc 2.39 or later, Ubuntu 24.04's), and the folder can go anywhere.

## Use

```bash
tar -xJf gfopenamigagcc-16.2.0-open9-x86_64-linux-gnu-x86_64-linux.tar.xz
make ARCH=x86_64 CROSS_COMPILE=$PWD/gfopenamigagcc-16.2.0-open9-x86_64-linux-gnu-x86_64-linux/bin/x86_64-linux-gnu- ...
```

## Checks

`tests/linux-check.sh PREFIX x86_64` on the built toolchain: the identity, no GMP, MPFR or MPC shared library in gcc, cc1, as and ld, the x86-64 kernel's code flags (`-mcmodel=kernel`, no SSE or red zone, retpolines, `-mharden-sls=all`) compile to `elf64-x86-64`, control-register instructions assemble, `-m32` (the 32-bit vDSO) and `-m16` (real-mode code) compile, libgcc is there, and a freestanding program (`tests/linux/hello-x86_64.c`) prints `x86_64 ok`, run natively, at `-O2` and `-Os`. `tests/linux-recipe-test.sh` checks the recipe before the build.
